## 📌 项目简介

本项目是 **Robocon 2026 排球机器人** 的击球子系统（上板），与底盘控制板分离，实现 **二级击球** 逻辑：

1. **一级发球（本板）**：控制 **大疆 RM3508 电机**，将排球快速抛高（约 25cm）。
2. **击球**：接收本板触发信号，控制 **两个 Robstride04 电机** 带动击球机构，将下落中的排球向目标方向击飞。

两块主控板通过 CAN 总线或串口通信，时序精确配合。底盘部分与上一版本相同（全向移动 + VESC 电调）。

> 💡 **设计优势**：二级击球可显著提升出球速度与方向可控性，适应复杂战术需求。

## ✨ 主要特性

| 模块               | 实现方式/部件                                      | 关键参数/说明                              |
| ------------------ | -------------------------------------------------- | ------------------------------------------ |
| **主控**           | STM32F407VET6                                      | Cortex-M4 @ 168MHz，专用于击球逻辑          |
| **一级发球电机**   | 大疆 RM3508 无刷电机                               | CAN 通信，力矩/速度控制，将球击高           |
| **击球电机** ×2 | Robstride04 直流伺服电机                           | PWM + 编码器闭环，带动击球摆臂              |
| **球位检测**       | 光电门（红外对射）                                 | 上升沿/下降沿中断，触发击球时序             |
| **板间通信**       | CAN 总线 或 USART                                  | 发送“击飞请求”信号至下板，接收状态反馈       |
| **任务调度**       | FreeRTOS v10.x                                     | 分离检测、电机控制、通信、监控任务          |
| **电机驱动**       | RM3508 通过 CAN 指令控制；Robstride04 通过 CAN 指令控制 | RM3508 控制周期 2ms，Robstride04 控制周期 2ms |

## 🧱 硬件平台

| 组件               | 型号 / 规格                                        |
| ------------------ | -------------------------------------------------- |
| **主控 MCU**       | STM32F407VET6（168MHz，CAN，多路 TIM）             |
| **一级发球电机**   | 大疆 RM3508（CAN 接口，减速比 1:19，扭矩 ~2.5N·m） |
| **击球电机** ×2 | Robstride04（12V 直流减速电机，集成霍尔编码器）    |
| **球位传感器**     | 光电门（安装于击球点下方）                     |
| **板间通信**       | CAN 收发器 TJA1050 或 串口直连（TTL）              |
| **电源**           | 24V（RM3508）+ 12V（Robstride04）+ 5V（主控/传感器） |

> **接线简表**
> | 功能                 | STM32F407 引脚              |
> |----------------------|-----------------------------|
> | CAN1（RM3508 + 下板） | PB8 (RX), PB9 (TX)          |
> | 光电门输入           | PE0 (EXTI 中断)             |
> | 调试串口             | PA9 (TX), PA10 (RX)         |

## 🧠 软件架构

### 模块功能说明表

| 模块               | 文件                       | 核心职责                                                     |
| ------------------ | -------------------------- | ------------------------------------------------------------ |
| **系统启动**       | `main.c` → `freertos.c` → `Task_Init.c` | HAL 初始化，创建任务，启动 FreeRTOS 调度器                     |
| **一级发球**       | `rm3508_drive.c`           | RM3508 CAN 指令封装：速度模式/位置模式，击高动作曲线（梯形速度） |
| **击球**       | `robstride04_ctrl.c`       | 两个 Robstride04 电机的独立 PID 控制（速度环 + 位置环），带动摆臂击飞 |
| **球位检测**       | `photo_gate.c`             | 光电门中断服务程序，记录球到达时刻，触发击球时序               |
| **板间通信**       | `inter_board_com.c`        | 与下板通信协议：发送击飞触发码、接收下板就绪/完成状态           |
| **任务调度**       | `tasks.c`                  | 创建检测任务、RM3508 控制任务、Robstride04 控制任务、通信任务  |
| **公用模块**       | `can_drive.c`, `pid.c`     | CAN 总线底层驱动、PID 控制器（供 Robstride04 使用）            |
